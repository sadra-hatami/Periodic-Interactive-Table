# 📖 About

**Mendeleev Interactive Table** is an interactive educational application developed with **Python** for exploring the periodic table and learning about chemical elements.

Instead of presenting the periodic table as a static image, the project transforms it into an **interactive environment** where users can select an element and immediately explore detailed information about it.

The application contains information for **all 118 known chemical elements**, including atomic structure, physical properties, periodic-table position, electron configuration, isotopes, and discovery history.

It is designed to make chemistry more visual, accessible, and engaging for students and anyone interested in exploring the elements.

> **Tagline:** *An interactive Python periodic table for exploring all 118 elements, their properties, atomic structure, and discovery history.*

---

# 🚀 Why Mendeleev Interactive Table?

Traditional periodic tables provide a large amount of information in a compact static layout.

Mendeleev Interactive Table was created to turn that static experience into an **interactive learning environment**.

Instead of searching through separate references for information about individual elements, users can:

* Select an element directly from the periodic table
* Explore its scientific properties
* View its atomic and subatomic information
* Examine its electron-shell structure
* Learn about its discovery
* Understand its position within the periodic table

The project focuses on:

* Making chemistry more interactive
* Helping students explore chemical elements
* Connecting atomic structure with visual representation
* Presenting complex information in an accessible interface
* Combining programming with science education

# 🖱️ Interactive Experience

The main interface presents the periodic table in its familiar organizational structure.

Users can interact directly with the elements:

1. Launch the application.
2. Locate an element on the periodic table.
3. Click the element.
4. Open its detailed information window.
5. Explore its atomic, physical, and historical properties.
6. Open the subatomic-particle information when needed.
7. View the electron-shell visualization.

The interface combines the **periodic-table layout**, **interactive selection**, and **dedicated information windows** into one learning experience.

---

# 🌀 Electron Shell Visualization

One of the interactive components of the project is the visualization of an element's electron-shell structure.

The application uses **Python Turtle Graphics** to generate a visual representation of electron shells.

The visualization includes:

* Concentric electron shells
* Electron placement around shells
* Support for multiple electron shells
* Visual representation of atomic electron distribution

This provides a more intuitive way to connect an element's electron configuration with its atomic structure.

---

# 🎨 Periodic Table Structure

The application organizes the elements according to the standard periodic-table structure.

It visually represents:

* **18 groups**
* **7 periods**
* Element symbols
* Atomic numbers
* Atomic masses
* Element categories
* Interactive element positions

Different element categories are visually distinguished through color coding, helping users identify related groups of elements more easily.

# ▶️ Usage

### Requirements

A Python installation is required to run the project.

### Run the application

Clone the repository and run the main Python file:

```bash
git clone https://github.com/sadra-hatami/Mendeleev-Interactive-Table.git
cd Mendeleev-Interactive-Table
python Mendeleev_Interactive_Table.py
```

### Basic workflow

1. Launch the application.
2. Explore the periodic table.
3. Click an element.
4. Review the element's detailed properties.
5. Open subatomic-particle information if needed.
6. Explore its electron-shell visualization.

# ❓ Frequently Asked Questions

### How many elements are included?

The application includes information for **all 118 chemical elements**.

### Is the periodic table interactive?

**Yes.** Users can click elements directly and open their detailed information.

### What information is available for each element?

The application provides atomic, physical, structural, periodic-table, and discovery information, including atomic number, atomic mass, electron configuration, valence information, isotopes, physical properties, ionization energy, and discovery data.

### Can I see the subatomic particles?

**Yes.** The application provides information about the number of protons, neutrons, and electrons.

### Does the application visualize electron shells?

**Yes.** Electron shells are visually represented using Turtle Graphics.

### Which programming language is used?

The project is developed with **Python**.

### Which GUI framework is used?

The graphical interface is built using **Tkinter and ttk**.

### Is this project educational?

Yes. The project is designed as an interactive educational tool for exploring chemistry and the periodic table.
